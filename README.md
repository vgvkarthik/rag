# RAG Project

This project is a small Retrieval-Augmented Generation (RAG) setup for working with local document data and a language model. It includes Python scripts for indexing and querying data, along with local vector storage and cached embeddings.

## What it contains
- Python scripts: rag-g.py and rag-st.py
- Local Chroma vector database in chroma_db/
- Cached embeddings in embeddings_cache/
- A local Python virtual environment in rag/

## Quick start
1. Activate the virtual environment from rag/Scripts/activate.
2. Run the desired Python script to build or query the RAG pipeline.
3. Make sure the model file and data files are present in the project folder.
